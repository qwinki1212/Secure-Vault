# Secure Vault 🛡️

**Secure Vault** — це кросплатформна комп'ютерна система для безпечного локального зберігання паролів у зашифрованому вигляді.

## 🎯 Мета проєкту (MVP)
Розробка надійного офлайн-сховища паролів, що вирішує проблему використання користувачами слабких паролів та запобігає витокам даних з хмарних сервісів. Проєкт створюється в умовах жорстких часових обмежень (15 тижнів до випуску MVP).

## ✨ Ключові можливості
* **Локальне шифрування:** Усі дані шифруються алгоритмом AES-256 виключно на пристрої користувача.
* **Авторизація:** Доступ до бази паролів здійснюється за допомогою єдиного майстер-пароля.
* **Генератор паролів:** Вбудований інструмент для створення криптостійких випадкових паролів.
* **Безпека:** Відсутність мережевої взаємодії та хмарної синхронізації (повна ізоляція даних).
* **Кросплатформність:** Підтримка ОС Windows, macOS та Linux.

## 🛠 Технологічний стек
* **Мова програмування:** C++
* **Алгоритм шифрування:** AES-256
